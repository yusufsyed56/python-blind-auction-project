# Blind Auction Python Project 🎯

A simple terminal-based Blind Auction program built using Python.

- Multiple bidders support
- Stores bids using dictionaries
- Automatically finds the highest bidder
- Interactive command-line interface
- Beginner-friendly Python project

- User Input Handling
